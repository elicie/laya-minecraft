# 경량 3D 관전

기본 관전 화면은 프로젝트의 TypeScript 클라이언트와 단일 메시 워커를 사용한다. Minecraft 데이터베이스와 전체 버전의 지형 변환 코드를 브라우저에 넣지 않는다. Mineflayer와 외부 라이브러리는 수정하지 않고 공개 월드·블록·엔티티 API로 실제 관측 정보를 읽는다. 관전 소켓으로 게임 명령을 실행하지 않는다.

봇이 서 있는 청크를 중심으로 반경 2청크, 높이 3구역을 가까운 순서로 전송한다. 블록 팔레트는 실제 접속 버전의 상태 ID와 속성을 유지한다. 화면은 텍스처·카메라·실제 지형 메시를 그린 후 준비 완료를 알린다. 이후 블록 변경을 반영하고 이동·재접속·차원 변경에 따라 오래된 구역을 정리한다.

카메라는 최대 20회/초, 엔티티는 최대 10회/초 갱신하며 움직임을 보간한다. 관측 내용이 같으면 1초 확인 신호만 보낸다. 화면 갱신은 최대 60회/초이고 정지된 장면에서는 그리기를 쉰다. 픽셀 비율은 1로 제한한다. 전송·지형 계산·GPU 업로드 큐에는 한도가 있다.

가까운 지형을 빠르게 관찰하는 화면이다. 인물과 생물은 관측된 크기·위치·이름으로 표시한다. 일부 복잡한 블록은 공개 충돌 형상으로 간소화한다. 해당 버전의 텍스처가 없으면 1.21.4 텍스처를 블록 이름으로 찾으며 간소화 사실을 표시한다. 블록 상태 ID를 다른 버전으로 바꾸지 않는다. 전체 Minecraft 클라이언트의 스킨·조명·원거리 묘사와는 차이가 있다.

## 빌드와 배포

`npm run build`는 먼저 `npm run build:viewer`로 `public/compact-viewer`에 클라이언트·워커·Three 모듈·텍스처를 생성한다. 개발과 테스트 명령도 필요한 관전 자산을 먼저 생성한다. 서버만 따로 빌드한다면 관전 자산도 별도로 빌드해야 한다.

운영 릴리스에는 서버·웹 빌드와 `public/compact-viewer`를 함께 포함한다. `LAYA_VIEWER_ASSET_ROOT`로 자산의 절대 경로를 지정할 수 있다. API·봇 워커·Vite preview가 같은 디렉터리를 사용해야 한다. Vite dev/preview와 API는 내용 해시가 붙은 공통 URL에 immutable 캐시와 gzip을 적용한다. 자산이 없으면 이전 뷰어로 자동 전환하지 않고 `VIEWER_ASSETS_NOT_BUILT`를 반환한다. `/api/v1/health`의 `viewerProtocol`은 `compact-voxel-v1`이다.

## 검증

일반 테스트에서 실제 공개 청크 자료의 인코딩, 블록 형상, 큐 한도, 델타·재접속·차원 전환을 확인한다. 브라우저 테스트는 실제 WebGL로 지형 픽셀·준비 완료·프레임 유지·이동 보간·정지 시 그리기 중단을 확인한다.

```bash
npm test
npm run build
npm run test:web
MC_HOST=127.0.0.1 MC_PORT=25566 npm run test:live -- compact-viewer.live
```

실제 서버 검증은 `minecraft-laya-validation:25566`에서 접속·관측만 수행하고 공개 블록 상태를 전송 내용과 대조한다. 관리용 테스트나 지형 생성 명령을 생존 월드에서 실행하지 않는다. Headless SwiftShader 성능 수치는 사용자의 GPU 프레임 속도를 뜻하지 않는다.
