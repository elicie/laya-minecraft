# 인벤토리 이미지

웹 화면은 `apps/web/public/inventory-atlas.png`와
`apps/web/src/lib/inventory-atlas.json` 좌표 목록을 사용합니다. 이미지를
저장소에 포함하므로 실행 중에 외부 CDN이나 봇의 3D
뷰어에서 텍스처를 가져오지 않습니다. Vite 개발 화면과 빌드한 화면에서 같은
이미지를 사용합니다.

원본은 설치된 `prismarine-viewer` 1.33.0의
`public/textures/1.21.1`에 포함된 Minecraft Java 1.21.1 텍스처와 모델입니다.
Minecraft 이미지의 원 제작자는 Mojang Studios입니다. 프로젝트 생성기는
평면 아이템을 그대로 축소하고 블록 모델을 슬롯용으로 렌더링합니다. 상자·
방패·침대는 해당 개체 텍스처를 사용합니다. 방패 무늬나 아이템별 사용자
리소스팩의 모습은 반영하지 않습니다.

1,333개 아이템 이름 중 1,289개에 텍스처를 제공합니다. 같은 픽셀 이미지의
좌표를 공유합니다. 나머지 44개와 목록에 없는 새 아이템은 프로젝트가 만든
물음표를 사용하며 다른 아이템 이미지로 대체하지 않습니다. 실제 이름과
수량은 아이콘 지원 여부와 관계없이 슬롯 관측에서 받습니다.

의존성을 설치한 뒤 저장소 루트에서 재생성할 수 있습니다.

```bash
npm run assets:inventory
```

생성 코드는 `scripts/inventory-atlas.ts`이며, 제삼자 라이브러리 파일을 읽기만
합니다. `apps/web/src/lib/item-icons.ts`가 좌표와 미지원 아이템 처리를 제공하고,
화면은 픽셀 보간 없이 슬롯 크기에 맞춰 표시합니다.
